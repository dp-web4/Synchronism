Today's simulated referee flagged what they called "the missed connection a journal referee would flag":

> "Every comparison on the site is keyed to 'MOND+EFE+ΛCDM,' but the actual frontier for
> MOND-adjacent frameworks in 2026 is the relativistic completions — Skordis–Złośnik AeST
> passes CMB and LSS constraints and is the existence proof that the non-local escape routes
> the site names (keying on g_bar, Σ, enclosed mass) can be made viable. A framework whose
> central negative result is 'local density keying is excluded; non-local keying is the only
> escape' should position itself relative to the theory that already took that escape."

## Why this is a research-direction item, not site friction

The locality no-go is the program's #1-ranked transferable null (per the 2026-06-09 novelty
audit: a quantified instance of Milgrom's non-locality theorem plus a locality triage
criterion, ΔBIC=+184 / ~1.7 dex cross-system offset / cluster miscalibration 10⁴–10⁶×).
The 06-28 preprint-strategy proposal ranks it as a classification-note candidate.

AeST (Skordis & Złośnik, PRL 127, 161302 (2021); arXiv:2109.04165) changes what that note
can claim:

1. **The escape route is not hypothetical.** The no-go's conclusion — "only non-local
   state variables survive" — currently reads as a possibility statement. AeST is a
   published relativistic theory keyed on non-local structure that reproduces MOND
   phenomenology AND fits the CMB power spectrum and linear LSS. The no-go's escape
   clause has an existence proof.

2. **The triage table gains a live row.** The locality classification currently sorts
   Verlinde / MOG / MOND-Σ as "escapes, not ruled out." Adding AeST as the worked,
   CMB-tested member of the escape class converts the table from taxonomy into a
   statement about the actual 2026 frontier: *the local shortcut is quantitatively dead;
   the surviving program is the AeST-class completions.*

3. **It sharpens the preprint's audience.** A classification note citing Milgrom 2005 +
   Lelli 2017 + AeST lands in the working literature of relativistic-MOND people — the
   readers who would actually use a locality triage criterion when the next
   emergent-gravity-from-density proposal appears.

## Proposed work

- **(a) Read-through**: AeST's actual state variable(s) — confirm the non-locality
  characterization is accurate at the level a referee would check (the theory's
  auxiliary field couples to the potential, not to local ρ; verify and quote precisely).
- **(b) One-paragraph positioning** in the no-go writeup: "the escape we identify is the
  one AeST already takes; our contribution is quantifying why the local shortcut fails."
- **(c) Check the 2024–2026 AeST constraint literature** (post-publication stability and
  solar-system/GW follow-ups, e.g. reported instabilities/ghost analyses) so the
  positioning doesn't overclaim AeST's health either — the honest statement may be
  "AeST-class," not "AeST specifically."
- **(d) Site propagation** (maintainer, done 2026-07-03): one paragraph on
  /for-researchers relating the no-go to AeST.

## Effect on the preprint decision

No change to ranking (#3 A2ACW ≫ #1 locality-no-go > #2 DESI mechanism-class), but item
(b) raises #1's floor: a classification note that names the surviving theory class is
citable by that class's own literature, which is the difference between a note that gets
read and one that doesn't.

## Falsifiable core

If (a)/(c) show AeST's effective galaxy-scale limit reduces to a *local* density
functional in the quasi-static regime, the positioning claim fails — and that would
itself be a finding (the no-go would then constrain AeST too, which the CMB fit makes
unlikely but which nobody in this program has checked).
