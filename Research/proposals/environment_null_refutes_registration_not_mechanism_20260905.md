## The observation (verified against what the site and archive already print)

Three numbers, all already published, never put side by side:

| quantity | value | where |
|---|---|---|
| C(ρ) ambient-density lever at SPARC outer radii | ≤ 2 × 10⁻³ dex (field 2×10⁻⁵ … δ~100 group 2×10⁻³) | `/tier-1-existing` TEST-05 alert; PREDICTIONS TEST-10 row |
| RAR scatter the lever competes with | 0.086–0.13 dex | McGaugh+16 / site |
| **implied r² from the equation's own lever** | (0.002/0.1)² ≈ **2–5 × 10⁻⁴**, an upper bound | arithmetic |
| **measured r² (TEST-08 registered run, 2026-07-14)** | **1 × 10⁻⁴** (N = 141, Cosmicflows-4) | PREDICTIONS TEST-08 row |

The executed null is **consistent with the equation's own predicted amplitude** to within a factor of a few, and
the equation's number is an upper bound. What the run refuted is the *registered* claim — S177's ">20% of RAR
scatter from environment" (kill bar r² < 0.09), which would need ~0.05 dex of modulation, **25× more than C(ρ)
at galaxy-calibrated ρ_crit can supply**. The archive already says half of this: the TEST-10 row records that
"the framework registered a >20% environment effect its own equation cannot produce." It has not drawn the
classification consequence.

## Proposed reclassification

TEST-08 row, Bucket 2 — keep it in Bucket 2 (S177's registered claim was tested against data and failed; that is
a genuine, permanent elimination) but re-label **what died**: *"the S177 registration (>20% environment share)
— an amplitude never derived from C(ρ), which itself predicts r² ~ 10⁻⁴, consistent with the measured 10⁻⁴."*
Class: **registration-specific**, not mechanism-specific. The row's transferable content becomes: *the RAR is
a universal local law to r² < 10⁻⁴ against ambient density* — a clean null MOND+EFE must also live with (its
lever is ~50× larger; the null's weak secondaries are EFE-signed, so it does not contradict Chae+2020 —
different estimator).

The dp-gated question "6 → how many independent roots?" currently has three live answers on the site (2 on the

call; what this proposal asks is that whichever figure is chosen, the environment row not be counted as a
refutation of C(ρ)'s mechanism, because C(ρ)'s mechanism predicted the outcome.

## What would refute this proposal

Show that the equation, at the ρ_crit the galaxy fits actually use, predicts an ambient-density modulation
≥ 0.03 dex (r² ≳ 0.09) at SPARC outer radii. The site's TEST-05 lever computation
(`explorer/scripts/test05_environment_lever_magnitudes.py`) says it cannot; re-running it with the 09-03
placement result (ρ_crit 2.5×10⁴ above the sampled densities ⇒ C ≈ γx, linear, lever ∝ δρ/ρ_crit) should make
the lever *smaller*, not larger. If someone finds the opposite, the row goes back to mechanism-specific.
